# Fıkıh Usulü · Giray Akademi

Fıkıh usulü için ünite ünite konu anlatımı, karşılaştırma tabloları, kavram kartları, eser–müellif eşleştirme, açıklamalı testler ve geçmiş sınav soruları.

Adres: https://alpkiraym.github.io/fikih_usulu/

## Üniteler
1. Giriş: Fıkıh, Usûl-i Fıkıh ve Telif Yolları
2. Şer'î Deliller
3. Mebâhisu'l-Ahkâm
4. Lafızlar ve Delalet
5. Teşriî Usûlî Kaideler
6. Tearuz ve Tercih

## Düzenleme
İçerik `kaynak/` klasöründedir: ünite metinleri `01.txt…06.txt`, test soruları `sorular.txt`, geçmiş sınav ve soru–cevap çalışması `sinav.txt`, görünüm `sablon.html`. Değişiklikten sonra:

```
python3 kaynak/derle.py
```

`index.html` elle düzeltilmez.

## Kaynaklar
- Baltalı ders notu (el yazısı defter)
- Fıkıh Usûlü 2022 1. dönem sınav soruları
- Usul-i Fıkıh soruları ve cevapları (icmâ, kıyas, illet)

İlerleme yalnızca tarayıcıda (`fu_` ön ekiyle) saklanır.
